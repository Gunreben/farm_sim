# Notes for agents

- Keep `README.md` clean and up to date. When you add or change a feature, CLI flag, config key,
  topic, actor type or known limitation, update the matching README section in the same change
  (and the Layout list for new modules). Remove what is no longer true instead of appending.
- Screenshots for the README go in `docs/images/` (webp/png, keep them small).
- `assets/` (except `assets/poses/`) and `out/` are generated and gitignored; never commit them.
